# DeepRecurrentEncoder

Documentation for [DeepRecurrentEncoder](https://github.com/behinger/DeepRecurrentEncoder.jl).

Welcome to [DeepRecurrentEncoder.jl](https://github.com/s-ccs/DeepRecurrentEncoder.jl): a Julia package to Train and test a deep recurrent encoder with ease

## Installation

clone the repo from the link above and start up julia inside the cloned project

```julia-repl
julia> using Pkg; Pkg.add(".")
```


## Where to start: Learning roadmap

### 0. First first steps

📌 Goal: Familiarize yourself with EEG signals and Auto encoders.
🔗 [EEG signals](https://www.ebme.co.uk/articles/clinical-engineering/introduction-to-eeg#:~:text=The%20electroencephalogram%20(EEG)%20is%20a,animals%20as%20early%20as%201870.) | [Auto Encoderes](https://www.geeksforgeeks.org/auto-encoders/)

### 1. First steps

📌 Goal: Learn to fit a model with DeepRecurrentEncoder package
🔗 [Tutorial for basic usage](https://www.s-ccs.de/DeepRecurrentEncoder.jl/dev/generated/howto/basicUsage)

### 2. Intermediate topics

📌 Goal: Explore effect of hidden channels and various stimuli on the encoder
🔗 [Effect of hidden channels](https://www.s-ccs.de/DeepRecurrentEncoder.jl/dev/generated/tutorials/hiddenChannelsEffect) | [Stimuli effect](https://www.s-ccs.de/DeepRecurrentEncoder.jl/dev/generatedtutorials/stimuliEffect/)


You should also Read the paper on which the current version of the model is based on [Link to article](https://arxiv.org/pdf/2103.02339). Enjoy!
